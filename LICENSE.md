# License and Attribution Policy

Repository-authored documentation is available under the [Creative Commons
Attribution-ShareAlike 2.0 Generic license](https://creativecommons.org/licenses/by-sa/2.0/)
unless a file says otherwise.

Drupal.org user-generated content, including issue titles and other narrative
fields retained in a future projection, remains subject to Drupal.org's
[Terms of Service](https://www.drupal.org/terms). Those terms license non-code
content under Creative Commons Attribution-ShareAlike 2.0, except where the source
identifies a different license. Each retained record or its manifest must preserve:

- the issue title and canonical Drupal.org URL;
- creator name or pseudonym as supplied by the source, without importing broader
  profile data;
- source identifier and retrieval time;
- the applicable license name and URI, including source-specific exceptions; and
- a notice that the source was normalized into a retained projection, with the
  canonicalization version.

If the source does not supply usable creator credit, the independent pilot's named
evidence reviewer and repository maintainer must document and approve a reasonable
collective-credit method before candidate creation. Mike Gifford's acceptance is
additionally required before that method is characterized as upstream/community
policy. This policy is not legal advice, and a human must review attribution before
publishing a projection.

This Phase 0 package contains no collector code. The Phase 1 implementation plan
selects GNU General Public License version 2 or later for Drupal-aligned collector
code. That license applies only after the corresponding code and license text are
added; this document does not license code that does not yet exist.

[OpenACR](https://github.com/GSA/openacr) is a United States government project
whose repository states that its work is public domain by default. This pilot
borrows no OpenACR code, schemas, catalogs, or report content. Any future reuse
must retain the applicable OpenACR and third-party license notices.
